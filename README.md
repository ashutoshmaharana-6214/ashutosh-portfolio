# Ashutosh Maharana — Portfolio

React + TypeScript + Tailwind CSS portfolio website.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
```

The generated `dist/` directory can be deployed to Vercel or Netlify.

## Before publishing

- Verify GitHub, LinkedIn and LeetCode profile URLs.
- Replace the general GitHub profile links in the project cards with exact project repository URLs.
- Add your email address and resume download link.
- Verify internship title and all technical experience details.
- Update skills and project statuses as implementation evolves.
